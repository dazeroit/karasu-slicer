# Built-in printer catalog

The printers, resins and print settings compiled into karasu-slicer, grouped by vendor:
`printers/`, `materials/` and `print-settings/`, with `catalog.json` listing them. They are
generated by `tools/assets/make_catalog.py`; do not edit them by hand.

Where each value comes from, karasu-slicer's own choices and the catalog's known limits:
[docs/CATALOG-SOURCES.md](../../docs/CATALOG-SOURCES.md).
